# РОЗРОБКА ВЕБ-ПЛАТФОРМИ ДЛЯ ВЕДЕННЯ ОСОБИСТИХ ФІНАНСІВ З ІНТЕРАКТИВНОЮ АНАЛІТИКОЮ ЯК ІНСТРУМЕНТ ПІДТРИМКИ ПРИЙНЯТТЯ РІШЕНЬ

У сучасному цифровому середовищі управління особистими фінансами стає складнішою задачею через зростання кількості фінансових інструментів, платіжних сервісів та джерел доходів [1]. Поширення безготівкових платежів, електронних гаманців і криптовалют формує нові вимоги до інструментів обліку та аналізу фінансової діяльності користувачів [2]. У таких умовах особливо актуальним є створення систем, що забезпечують не лише фіксацію транзакцій, але й аналітичну підтримку прийняття фінансових рішень [3].

Незважаючи на існування значної кількості програмних рішень у сфері персональних фінансів, більшість із них мають низку обмежень: недостатній рівень аналітики, відсутність підтримки мультивалютності, складність користувацького інтерфейсу або обмежені можливості інтеграції [4]. Це зумовлює необхідність розробки універсальної веб-платформи, яка поєднує функції обліку, планування та аналізу фінансових даних [5].

Метою дослідження є розробка веб-платформи для ведення особистих фінансів з інтерактивною аналітикою, яка забезпечує централізоване управління фінансовою інформацією, підтримку мультивалютності та надання інструментів для аналізу фінансової поведінки користувача.

Архітектура запропонованої системи базується на клієнт-серверній моделі з чітким розділенням відповідальностей. Серверна частина реалізована із використанням асинхронного фреймворку FastAPI [6], що забезпечує високу продуктивність та ефективну обробку великої кількості паралельних запитів. Для зберігання даних використано реляційну базу даних PostgreSQL [8], структура якої спроєктована відповідно до принципів нормалізації та забезпечує цілісність і узгодженість даних. Клієнтська частина реалізована з використанням React та TypeScript [7], що забезпечує динамічний інтерфейс та взаємодію з сервером через REST API.

Основу функціоналу платформи складає модуль обліку фінансових операцій. Користувач може фіксувати доходи, витрати та перекази між рахунками, призначаючи кожній операції категорію, теги та довільний коментар. Система підтримує десять валют із щогодинним оновленням актуальних курсів через інтеграцію з API Національного банку України [2]. Завдяки цьому баланс і звіти завжди відображаються у зручній для користувача валюті незалежно від того, у якій валюті була здійснена операція. Для автоматизації регулярних платежів — оренди, підписок, зарплати — передбачено рекурентні транзакції: користувач налаштовує правило з потрібною частотою повторення, а система самостійно створює відповідні записи за розкладом [2].

Платформа підтримує не лише особисті, а й спільні фінанси. Модуль бюджетування дозволяє створювати бюджети трьох типів: особистий, сімейний та бізнесовий. Сімейні та бізнесові бюджети підтримують спільний доступ — власник може запрошувати інших користувачів та призначати їм різні рівні прав: лише перегляд, редагування або повне управління бюджетом. Кожен бюджет може мати встановлений ліміт витрат, який аналітичний модуль використовує для порівняння планових і фактичних показників.

Для довгострокового планування передбачено модуль фінансових цілей — своєрідних накопичувальних «банок». Користувач визначає цільову суму та може поповнювати або знімати кошти з цілі в будь-який момент. Коли накопичена сума досягає цільової, ціль автоматично переходить у статус завершеної. Такий підхід сприяє формуванню фінансової дисципліни та усвідомленого ставлення до заощаджень [1].

Аналітичний модуль є ключовим інструментом підтримки прийняття рішень [3]. Він надає користувачу сім видів звітів: загальний огляд доходів, витрат та балансу за обраний період; динаміку фінансових показників по місяцях та роках; порівняння поточного та попереднього аналогічного фінансового вікна; розподіл витрат і доходів за категоріями та тегами; а також оцінку виконання бюджету відносно встановленого ліміту. Усі звіти підтримують отримання результатів у будь-якій з підтримуваних валют. Використання інтерактивної візуалізації дозволяє представити результати аналізу у зрозумілій формі [4], що сприяє прийняттю обґрунтованих фінансових рішень.

Для зручності введення даних система підтримує завантаження фотографій та сканів касових чеків. Після завантаження автоматично виконується розпізнавання тексту: система визначає суму, назву торгової точки та категорію витрат, що значно прискорює процес фіксації операцій. Для масового перенесення даних з інших сервісів або банківських виписок реалізовано імпорт транзакцій із файлів CSV та Excel з детальним звітом про результати обробки кожного рядка.

Окремий модуль налаштувань надає користувачу централізований контроль над профілем: ім'я, аватар, часовий пояс, валюта за замовчуванням, адреса електронної пошти та параметри сповіщень. Передбачено два рівні підписки — базовий та розширений — із відповідним набором доступних функцій.

Особливу увагу приділено безпеці системи. Автентифікація побудована на парі JWT-токенів [9]: короткоживучий токен доступу та токен оновлення з автоматичною ротацією. Паролі перевіряються на надійність під час реєстрації, а також звіряються із загальновідомими базами витоків — без передачі пароля на зовнішні сервіси. Для додаткового захисту облікового запису реалізовано двофакторну автентифікацію на основі одноразових TOTP-кодів: при кожному вході з увімкненою 2FA користувач підтверджує особу кодом із мобільного застосунку-автентифікатора. Соціальна автентифікація через Google та GitHub дозволяє увійти або зареєструватися в один клік за протоколом OAuth2, при цьому обліковий запис автоматично прив'язується до існуючого профілю за адресою електронної пошти.

Серед ключових переваг розробленої системи можна виділити:
 – повний цикл управління фінансами в єдиному інтерфейсі: облік, планування, аналітика;
 – підтримку мультивалютності зі щогодинним оновленням курсів;
 – спільний доступ до бюджетів з гнучкою рольовою моделлю прав;
 – автоматизацію регулярних операцій через рекурентні транзакції;
 – сім видів аналітичних звітів з конвертацією у будь-яку валюту;
 – OCR-розпізнавання чеків та масовий імпорт даних;
 – багаторівневу систему безпеки: JWT, двофакторна автентифікація, OAuth2;
 – модульну архітектуру, що забезпечує легке масштабування та розширення.

Отже, розроблена веб-платформа є ефективним інструментом для управління як особистими, так і спільними фінансами, що поєднує функції обліку, планування та аналізу в єдиному рішенні. Платформа сприяє підвищенню фінансової грамотності користувачів [5] та створює передумови для подальшого розвитку інтелектуальних систем підтримки прийняття рішень у фінансовій сфері [10].

Перспективними напрямами подальших досліджень є інтеграція з банківськими API, використання методів машинного навчання для прогнозування фінансової поведінки, а також розширення аналітичного модуля з підтримкою бюджетних прогнозів.
